## Featured Projects

### ⚙️ Job Application Tracker — n8n Workflow Automation
> n8n · Google Forms · Google Sheets · Gmail · OAuth2

Two self-hosted n8n workflows that log each application from a Google Form into a Google Sheet and email a follow-up reminder two weeks later if the status is still "Applied". Built with AI as my partner: I directed the design with Claude, tested each step and checked the results. Designed for reliability, with an upsert on a unique ID to avoid duplicate rows, a "due on or before today" check so missed runs catch up, retries on safe steps only, and explicit timezone handling.

🔗 [Repo and documentation](https://github.com/jarquecarl/n8n-job-application-tracker)

---

### 🗂️ Digital Request & Approval System *(Internship and freelance work)*
> React 18 · JavaScript · Tailwind CSS · Firebase · Cloudinary

A company-wide digital replacement for paper-based request forms at HS Technologies, formerly called MRF Digitalization. It uses real-time data sync with Firestore, Firebase Auth so each approver only sees requests at their stage, Cloudinary media uploads, and a multi-step approval, denial and revision workflow. I developed it with a partner during my internship as the frontend developer, then continued as a freelancer on testing, troubleshooting and polish, with weekly reports to the company. This is company work, so the code isn't public.
